# スーパーヒーローへの道 — 改訂版 V4

承認済みの本文確認稿02を基に、プロローグ・EASY・NORMAL・HARD・EXTRA・現実への帰還までを統合した静的サイトです。元の試作01は別フォルダに保存しています。

## プレビューと公開

ZIPを展開し、`hero_puzzle_v4/index.html`を開いてください。画像・dataフォルダも一緒に置いてください。通常のプレイには追加インストールは不要です。

GitHub Pagesを更新する場合は、このフォルダの**中身**を現在の公開ルートに配置します。`index.html`だけの差し替えでは動きません。本納品では、公開中のGitHub Pagesや既存掲示板の変更は行っていません。

進捗はブラウザ内に保存します。同じ公開URL・ブラウザであればE/N/Hの保存キーを引き継ぎます。別端末やローカルファイルから公開サイトへの進捗同期はありません。EXTRAの旧LASTは設定が変わったため、旧版でLAST到達・クリア済みの記録は対峙の場面から再開します。それ以前の確認済み資料と生存確認は残します。

## 新しい掲示板

既存の掲示板を開くリンクや埋め込みではなく、同じ「GAS＋Googleスプレッドシート」方式で、謎解き専用の新しい投稿先を作る構成です。新しいシート・新しいApps Scriptプロジェクトを使い、既存掲示板の投稿・データは共有しません。

画面・投稿処理・部屋分け・カード表示・運営による非表示・重複送信の防止を用意しました。現在、`board-config.js`の`gasUrl`は未設定です。新規のウェブアプリを発行するまでは画面に「接続設定待ち」と表示し、投稿しません。別の掲示板IDが返る接続先でも投稿を有効にしません。

新規公開の手順は[board-gas/SETUP.md](board-gas/SETUP.md)、貼り付けるGASコードは`board-gas/Code.gs`です。Googleアカウントでのシート作成・権限承認・ウェブアプリのデプロイ後、新しい`/exec`のURLを設定してください。既存の投稿先URLは使用しません。

作中人物との送受信・生体情報・位置取得は物語内の演出です。新規掲示板を接続した場合、その投稿だけが実際の参加者と共有されます。
