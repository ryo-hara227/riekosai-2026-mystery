# HEROES! — EASY & NORMAL 試作サイト（Ver.2）

EASY編『ヒーロー、出動できません！』と、NORMAL編『緊急指令！街を守れ！』の試遊用静的Webサイトです。ユーザー制作の問題画像を使用しています。HARD・EXTRAは未実装です。HTML/CSS/JSのみで動作し、GASなどのサーバーは不要です。

## すぐに試遊する

1. ZIPを展開し、フォルダ内の`index.html`をブラウザで開くか、下記のGitHub Pagesへアップロードします。
2. 総合ページのEASYまたはNORMALから「最初から遊ぶ」を選びます。
3. 各問題では解答後に「次へ」が有効になります。不正解でもゲームオーバーにはなりません。
4. NORMALでは、ページ上部の「通信ログを確認」で、最初のログをいつでも見直せます。問題画像はタップで拡大表示できます。
5. 同じ端末・同じサイトURLでは進捗がブラウザのlocalStorageに別々に保存され、「続きから再開」が使えます。ブラウザの仕様上、`file://`で直接開いた場合は保存が不安定なことがあります。GitHub PagesなどHTTP(S)での試遊を推奨します。

## 既存のGitHub Pagesサイトへ反映するには

1. ZIP内のファイルとフォルダを、既存のサイトのリポジトリのルートへ配置します（ZIPそのものをアップロードしない）。
2. 更新するファイルは `index.html`, `styles.css`, `app.js`, `README.md`。既存EASYデータを維持したい場合は `data/easy.js`, `assets/easy/` の変更分も確認してください。
3. **追加するファイル**は `data/normal.js`, `assets/normal/n-01.png`, `n-02.png`, `n-last.png`。
4. GitHubのコミット後、Pagesの公開サイトでリロードして確かめます。過去のEASYのセーブキーは変更していないため、同じオリジンであれば以前の進捗を引き継げます。

新規公開する場合は、GitHubリポジトリの Settings → Pages → Deploy from a branch → main / (root) を選んでください。

| 画面 | 実装 | データ |

| N-00 | プロローグ、壊れた通信ログの提示 | `data/normal.js` と `assets/normal/n-last.png` |
| N-01 | 7セグ表示の修正。日付と時刻を2欄で回答 | `n-01.png`、ヒント2段階 |
| N-01 正解後 | 時刻が復元できたことを報告する会話 | `data/normal.js` |
| N-02 | あみだくじ。C-01〜C-04の地区を4欄で回答 | `n-02.png`、ヒント1段階 |

| CLEAR | 暫定合言葉「つなぐ」 | `data/normal.js` の `extraKeyword` |

### 台本や問題を直す場所

- ストーリーの段落は `data/normal.js` の該当ページの `paragraphs`、最後のシステム通知後は `afterAlert`。
- 各問題の題名、質問、ヒントは `title`, `prompt`, `hints`。
- N-01の正解は `fields` 内の `answers`。数字以外の区切り文字は無視して判定するため「11月29日」「11/29」「1129」、時刻なら「15:32」「1532」「15時32分」を許容します。
- N-02の正解は `fields` 内の `answers`。C-01=中央、C-02=東、C-03=西、C-04=響ヶ丘学園。
- N-LASTの選択肢は `choices`。エコー以外のヒーロー名は仮置きで、`correctChoice:'echo'` が正解です。
- 問題画像は `assets/normal` の同名ファイルを置き換えれば差し替えられます。
- EXTRA用のNORMAL合言葉は未確定のため `extraKeyword:'つなぐ'` を仮置き。
- CSSの基本配色は `styles.css` の `:root` にあります。NORMAL固有のカード・四択UIはファイル末尾の追加セクションで調整できます。

### セーブデータ

- EASY: `hero_easy_progress_v1`（旧版から維持）
- NORMAL: `hero_normal_progress_v1`（新規）

両方の進捗を消すときはページ下の「この端末のテスト進捗をリセット」を使用してください。公開後は各ページの`id`を変更すると保存済みの再開位置を失う場合があります。

## 作問者向けメモ（仮置き事項）

- プロローグ〜クリアのストーリーは仮稿です。人物名（ボルト、シグナル、ガード）と結末の細部は編集できます。
- NORMALの二問＋最終謎という構造に合わせ、以前のN-03案は追加していません。
- 11月29日15:32を現在時刻とし、通信ログを14:50（中央）→15:05（東）→15:20（西）→15:30（学園）と復元させる想定です。
- 不正プログラムや危険物の通報については、作中での犯行手口や危険物の扱いに踏み込まず、ヒーローによる安全確保へつなげています。
- 元画像の文字やレイアウトは加工していません。色・テキストの差し替えは作問者側の元データまたは画像ファイルで編集してください。
