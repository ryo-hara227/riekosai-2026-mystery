# HEROES — EASY編 試作サイト

「ヒーロー、出動できません！」をブラウザで遊べる **GitHub Pages向け静的サイト** です。
このZIPに `index.html`、`styles.css`、`app.js`、`data/easy.js`、各謎画像、仮会場マップをすべて入れています。**Google Apps Script・スプレッドシートは不要**です（メッセージボードとは現時点では別企画）。

## 1. まずプレイする

1. ZIPを展開します。
2. `index.html` をダブルクリックするか、後述のGitHub Pagesにアップロードして開きます。
3. `EASY / 最初から遊ぶ` を押します。
4. ストーリーを読み、謎では入力欄に解答して「解答する」を押します。
5. 正解すると「次へ」が押せるようになります。
6. ブラウザを閉じても、その端末・ブラウザの `localStorage` に現在位置と解答状況が保存されます。

`index.html` を直接開く方式でも多くのブラウザで動きますが、保存機能のテストには GitHub Pages やローカルWebサーバー経由を推奨します。

## 2. GitHub Pagesに新規公開する

1. [GitHub](https://github.com/) にログインして **New repository** を作成します（例 `hero-puzzle-2026`）。
2. ZIPの中の **ファイル／フォルダーの中身** をリポジトリのルートへアップロードします。ZIPを1個アップロードするのではなく、`index.html` がリポジトリの一番上にある状態にします。
3. `Commit changes` で保存します。
4. リポジトリの **Settings → Pages** を開きます。
5. **Build and deployment → Source: Deploy from a branch** を選択します。
6. **Branch: main / Folder: /(root)** を指定し、Saveします。
7. 公開完了後、表示されたURL（一般的には `https://ユーザー名.github.io/hero-puzzle-2026/`）にアクセスします。

変更時はGitHub上で対象ファイルを編集してコミットするか、ローカルで修正したファイルをアップロードし直します。更新後はブラウザを再読み込みしてください。

## 4. どこを編集すると何が変わるか

| 変更したいこと | 編集する場所 | 詳細 |
|---|---|---|
| 物語のセリフや説明 | `data/easy.js` → `pages` の `paragraphs` | 1要素が1段落。文中に不要な改行を挿入しない |
| ページ順やタイトル | `data/easy.js` → `pages` / `title` | 既公開ページの `id` は維持する |
| 各謎の正解・表記揺れ | `data/easy.js` → `fields` → `answers` | 配列に許容表記を追加 |
| 2つの解答欄 | `data/easy.js` → E-02 `fields` | `fields` 要素を増減。すべて正解でクリア |
| 問題画像を差し替える | `assets/easy/` の画像 + `image` パス | 画像名を変えなければデータ側編集不要 |
| 会場マップを描き直す | `assets/easy/e-03-map.svg` | PNG画像を使う場合 `image: 'assets/easy/任意.png'` に変更 |
| ステージへの道順 | E-03の `quote` | マップ修正時は必ず道順との整合を確認 |
| ヒントの数や文章 | 各問題の `hints` | 1個は「ヒント」、2個以上は「ヒント1」「ヒント2」 |
| EXTRA仮合言葉 | `data/easy.js` → `extraKeyword` | 現段階では「みつける」仮置き |
| ページ背景・配色 | `styles.css` 冒頭の `:root` | `--yellow`, `--red`, `--blue`, `--navy` など |
| フォント | `styles.css` → `--font-main` | 日本語の読みやすさ優先 |
| メインタイトル | `index.html` → `.cover` | タイトルや説明文を変更 |
| ボタンとカードの見た目 | `styles.css` → `.btn`, `.mission-card`, `.page-panel` | 境界線や影も変更可能 |
| セーブ方式・ナビ | `app.js` | 危険性が高いため慎重に変更 |
| テスト進捗を消す | サイトのフッター → リセット | 確認後にこの端末の進捗のみ削除 |

## 5. 背景を手描きイラストへ差し替える

背景は現在CSSのグラデーションとドット柄です。自作のイラストを固定背景として表示したい場合は、`assets/` に `my-hero-bg.webp` などを配置し、`styles.css` の `.background-art` を次のように変更できます。

```css
.background-art {
  position: fixed;
  inset: 0;
  z-index: -2;
  pointer-events: none;
  background: url('./assets/my-hero-bg.webp') center / cover no-repeat;
}
```

本文パネルは元から透過気味の白色にしてあるため、スクロールしても背景イラストが透けて見える構造です。読みやすさが落ちた場合は、`.page-panel` の `rgba(255,253,246,.94)` の最後の値を **1.0に近づける** と、透けを弱くできます。サイト共通の背景絵が未完成でも問題なく動くようにしてあります。

## 6. EASYの進捗と再開

`app.js` の以下のキーで進捗を保存しています。

```javascript
const STORAGE_KEY = 'hero_easy_progress_v1';
```

既公開後は、この文字列を安易に変えないでください。また `data/easy.js` の各 `pages[].id` と問題の `id` は、進捗を維持するために固定するのがおすすめです。文章・画像・ヒント・正解表記の追加であれば基本的に進捗への影響はありません。

※ この形式の保存は同じブラウザ・同じドメイン内だけで有効です。シークレットモード、異なる端末、サイトデータ削除では引き継がれません。

## 7. EASY初回テストの確認点

- E-01：「まいご」「迷子」で正解になるか
- E-02：○「きいろ」・△「ほし」を **両方** 入れると正解になるか
- E-03：マップの道順に矛盾がないか。答えは「メインステージ」
- E-LAST：迷子リストから「こはる」と導けるか
- 各問題で、正解前は次の画面へ進めないか
- ヒントの表示と画像拡大がスマホで動くか
- 途中で閉じて開き直して「続きから再開」が動くか
- STORYが冗長になっていないか。特に E-05 / E-06 / E-07 を試遊で調整
- 全体の所要時間が実際に約15分に収まるか
