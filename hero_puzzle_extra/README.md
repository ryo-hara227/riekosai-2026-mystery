# HEROES! EXTRA 試作01

提供された `hero_puzzle_v3.zip` に、EXTRA「ヒーローが消えた夜」を最後まで通せる形で追加しました。HTML/CSS/JavaScriptだけで動作し、外部サービス・サーバー処理・追加インストールは不要です。

## 遊ぶ・公開する

1. ZIPを展開し、`hero_puzzle_extra/index.html` をブラウザで開きます。
2. EXTRAカードの「EXTRAを開く」を押します。E/N/Hの合言葉を入力するか、「試作版をすぐに確認したい方へ」から試遊用に解禁できます。
3. Webで公開する場合は、このフォルダの**中身**を静的ホスティングの公開ルートに配置してください。GitHub Pages等で動作する構成です。

この納品物の作成時点では、外部ホスティングへの公開操作はしていません。ローカル保存のため、別端末・別ブラウザへ進捗は同期されません。ブラウザの設定で保存できなくても、現在の画面内ではプレイできます。

EASY / NORMAL / HARDのデータ・画像・保存キーはVer.3から維持しています。EXTRAだけを別キー `hero_extra_progress_v1` に保存します。各コースの「最初から」はそのコースだけを、フッターのリセットは4コース全部を消去します。

## 追加した流れ

| パート | 内容 |
|---|---|
| 解禁・プロローグ | E/N/Hの合言葉、後夜祭、マネージャーに届いたメール |
| First Mission | 7枚の原画像を4資料にまとめ、掲載順と異なるヒント番号・消えた数字・答えを復元 |
| Firstの最終指示 | 原画像を使い、旧校舎地下機械室の赤い扉へ進む |
| Second Mission | 原迷路に経路メモ、同色扉ワープ操作、作品由来の試作用扉コードを追加 |
| 発見した資料 | 計画書と日記を文章化して紙面風に表示。取消線は実行済み。エコーの音声は文字起こしの仮稿 |
| Third Mission | 指令履歴・原扉ログ・試作用復元時刻・通信経路・地下図を統合して報告 |
| 生存確認 | 装備近距離通信の受信拡張を導入し、現在更新される生体信号を確認 |
| LAST Mission | 宛先未指定SOSの扱いを修正。受付・返信経路を確立し、正式位置の要求→受領→救助班へ連絡 |
| エンディング | ヒーローの救出、日記の人物の保護依頼、クリア記録 |

## 仮実装と確定素材の境界

- EX01と迷路は提供された画像を無加工で使用しています。EX01の掲載順は A=`ex01_1`、B=`ex01_2-*`、C=`ex01_3-*`、D=`ex01_4` のままです。
- 指令履歴のH-101〜H-104は画像(7)を文章化しました。H-105〜H-114、受付原簿のID、通信経路は試作用に追加しました。最後の指令はエコーです。
- 画像(8)は原図のまま表示しています。**原図の時刻復号は未確定**です。別に明示した「試作用の復元時刻」を調査の採点に使います。これを原図の確定解法として扱わないでください。
- Secondのコードと色の対応・最終扉の採点は**仮の正解条件**です。APF/TNF/AWI/KKCは提供ログに合わせていますが、作品からの命名・色対応は試作案です。ゲーム内の「試遊補助」に仮の通過条件を表示しています。
- 迷路の経路メモは自由描画です。壁衝突・最短経路・通過文字の自動採点はありません。原画像の迷路を見ながら解く仕様です。
- 地下図は今回作成した縮尺なしの仮図面です。Thirdで現在地を断定せず、LASTの返信で初めて位置IDと救出経路が判明します。
- 生体データ、更新時刻、位置照会、救援送信は物語内のシミュレーションです。実端末や実在する人への通信、現在地の取得、外部送信は行いません。
- LASTの「宛先未指定のSOSを破棄する設定」は最終ギミックの試作案です。修正条件・正式な区画名・位置IDは設定から交換できます。
- 隊員同士の実通信・掲示板連携は未接続です。バッジの正式デザインはVer.3と同様に差し替え枠です。

## 編集する場所

| 変更する内容 | ファイル |
|---|---|
| EXTRAの物語、紙面の文章、合言葉、正解、追加ログ、試作用時刻 | `data/extra.js` |
| EXTRAの画面・操作・採点・受信・修正演出 | `extra-ui.js` |
| EXTRAの見た目 | `extra.css` |
| 地下の仮図面 | `assets/extra/basement-map.svg` |
| 共通の画面遷移と保存 | `app.js` |
| トップページ | `index.html` |

差し替え時は `data/extra.js` の `config` と、必要に応じて `extra-ui.js` の説明・ヒントも整合させてください。公開済みのページID・保存キーを変更すると途中再開に影響します。

ネタバレを含む試遊手順は `AUTHOR_GUIDE.md`、旧Ver.3の説明は `README_V3.md` にあります。ホスティングでは作者向けの `.md` を除外してもゲームは動きます。静的サイトのため、ソースを読めば解答は確認できます。
