# HEROES! 試作サイト Ver.3 — EASY・NORMAL・HARD

EASY / NORMAL は前回の公開用 Ver.2 の文章・画像・回答を基本的に保持し、HARD を追加した静的サイト（HTML/CSS/JavaScript）です。スマホ対応・途中保存・拡大表示に対応します。

## 公開・動作確認

1. ZIP を展開します。
2. 展開された `hero_puzzle_v3` フォルダの**中身**（`index.html`、`app.js`、`styles.css`、`data`、`assets`）を GitHub Pages の公開ルートにアップロードします。`hero_puzzle_v3/index.html` のままサブフォルダに置くとトップページが置き換わらないのでご注意ください。
3. `index.html` をブラウザで開くか、GitHub Pages の公開 URL でアクセスします。ローカル環境によっては `file://` のストレージ保存が使えない場合があるので、公開URLでの確認を推奨します。
4. 以前のファイルがキャッシュされている場合は強制再読み込みを行ってください。Ver.3 では CSS/JS の参照に `?v=3` を追加済みです。

**早解きへの対応**：最初から `旧校舎` と `1129` に気づいた場合は、誤答イベントを通らず救助へ進みます。ゲームオーバーはありません。他の場所を選んだ場合は、その場所に子どもたちがいない旨を通知して同じマップから再挑戦できます。

### 画像の配置

- `assets/hard/h1-route-map.png`：8問を一つに配置した**編集・差し替え可能な仮の大マップ**（ユーザー提供問題画像から合成）。誤分岐の施設名や選択肢は仮案です。最終デザインができたらこの画像を差し替えてください。
- `assets/hard/h1-01.png` ... `h1-08.png`：H-01の原問題画像（最新のH1-08を使用）。大マップの製作素材として保管。
- `assets/hard/h2.png`：変更後の最新版H-02（書籍アイコンなどがある方）。
- `assets/hard/h-yokoku.png`：予告状画像。
- `assets/hard/machine.png`・`island.png`：ユーザー提供の機械と離島のイラスト。

マップはゲーム内でスクロール・拡大・縮小できます。**個別の小謎ごとの回答や道順はWebアプリ側で保存しない**方式です。到達地点だけを回答する仕様です。

## 編集するファイル

| やりたいこと | 対象 |
|---|---|
| HARDの台詞、説明、ヒント、合言葉を変更 | `data/hard.js` |
| EASYの台詞、ヒント、解答を変更 | `data/easy.js` |
| NORMALの台詞、ヒント、解答を変更 | `data/normal.js` |
| トップページの文面・ミッション名を変更 | `index.html` |
| 色・余白・ボタン・マップの見せ方を変更 | `styles.css` |
| 遷移・採点・進捗保存を変更 | `app.js` |
| HARDのマップ画像を変更 | `assets/hard/h1-route-map.png` |

各ページの `id` と保存キーは途中再開に使用しています。公開後はできるだけ変更しないでください。EASY・NORMALの既存保存キーは維持しています。

## HERO LINK と受賞画像の仮実装

- 画面右下の「HERO LINK」から、どの問題中でも受信中の任務と活動記録を確認できます。閉じると問題画面へ戻ります。
- **隊員通信の実際の掲示板連携は未実装**です。ここには接続前のプレースホルダーを配置しています。送信・受信が動くと見せかける実装はしていません。
- トップ画面の「遊び方」「あらすじ」「注意事項」は折りたたみ表示です。
- 各コースのクリア画面にはバッジ画像枠があります。デザインが完成したら、`assets/rewards/easy-badge.png`、`normal-badge.png`、`hard-badge.png` を配置するだけで自動表示されます。画像がないときは仮のバッジ枠を表示します。
- EXTRAはストーリー案のみ更新し、プレイ機能はまだありません。
